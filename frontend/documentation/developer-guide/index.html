Bzade Developer Guide

Create email schedules, manage recipients, and use Google Sheets for personalization.

Overview

Bzade sends email on a one-time or recurring schedule through a connected Gmail or SMTP account.

  • Scheduling: Send once or repeat on a supported schedule.
  • Recipients: Enter addresses or select rows from Google Sheets.
  • Personalization: Insert spreadsheet values into the subject and message.

Common workflows

Use schedules for reminders, follow-ups, and recurring customer updates.

  • Appointment reminders: Schedule a message before an event.
  • Order follow-ups: Contact customers after a purchase.
  • Recurring updates: Send regular email to a saved recipient list.

API access

Production base URL: https://api.bzade.app. Requests use JSON and require a signed-in account.

Authentication

Send the signed-in user's Supabase access token as a Bearer token. API keys are not supported.

HTTP Header 
Authorization: Bearer <access_token>

Create a schedule

POST /api/schedules

Field Type Description
project_id UUID Required. UUID of the project that owns the schedule.
email_connection_id UUID Required. An active Gmail or SMTP connection.
name String Required. A label for the schedule.
schedule_type String one_time or recurring.
scheduled_for ISO 8601 First send time.
timezone IANA zone Time zone for the send time.
schedule_rule Object Required for recurring schedules; for example, {"every":"weekday"}.
config Object Recipients, optional cc/bcc, subject, body, and body_type.
cURL Example 
curl -X POST "$BZADE_API_URL/api/schedules" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "project_id": "11111111-1111-4111-8111-111111111111",
    "email_connection_id": "22222222-2222-4222-8222-222222222222",
    "name": "Order follow-up",
    "schedule_type": "one_time",
    "scheduled_for": "2026-11-27T09:00:00+01:00",
    "timezone": "Africa/Lagos",
    "config": {
      "recipients": ["customer@example.com"],
      "subject": "Your recent order",
      "body": "<p>Thank you for your order.</p>",
      "body_type": "html"
    }
  }'

Set BZADE_API_URL to your backend URL and ACCESS_TOKEN to the signed-in user's access token.

Email delivery

Each To address gets a separate email. Optional Cc and Bcc recipients receive each send; Bcc stays hidden from other recipients.

Invitations

Invitations support account or project scope. They are stored as pending and do not yet grant collaborator access. Available roles are Owner, Admin, Editor, and Viewer.

Google Sheets recipients

Connect Google Sheets, select a spreadsheet and row range, then map columns to template variables. Bzade sends one personalized email per valid row. Sheets requires its own Google connection.

JavaScript example

Fetch API 
const response = await fetch(`${BZADE_API_URL}/api/schedules`, {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${accessToken}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify(schedule),
});
const result = await response.json();
if (!response.ok) throw new Error(result.message || "Request failed.");

Errors

Error responses include a code and message. Validation errors also include fieldErrors to identify fields to correct.
